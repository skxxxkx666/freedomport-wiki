路由器配置指南 ​

本文档提供了各种路由器系统的代理配置方案，帮助您在路由器层面实现网络代理功能。

支持的路由器系统 ​

OpenWrt 系统 ​

  • OpenClash - 基于 Clash 的 OpenWrt 插件
  • 官方文档
  • 功能强大，支持规则分流
  • 适合高级用户

Koolshare 固件 ​

  • KoolClash - Koolshare 专用 Clash 插件
  • 官方文档
  • 界面友好，配置简单
  • 适合 Koolshare OpenWrt/LEDE 用户

梅林固件 ​

  • Clash-Merlin - 华硕梅林固件专用
  • 项目地址
  • 稳定可靠
  • 专为华硕路由器优化

Shell 脚本方案 ​

  • ShellCrash - 通用 Shell 脚本
  • 项目地址
  • 兼容性强，支持多种系统
  • 轻量级解决方案

Surge 方案 ​

  • Surge Router - 企业级解决方案
  • 官方手册
  • 专业级功能
  • 适合高端用户

选择建议 ​

路由器类型推荐方案难度等级特点
OpenWrtOpenClash进阶功能最全
KoolshareKoolClash简单易于配置
华硕梅林Clash-Merlin简单稳定可靠
其他系统ShellCrash进阶通用性强
企业环境Surge高级专业级别
